# 投稿说明草稿

## 作品名

校园采购守门员

## 一句话说明

把活动需求和供应商报价整理成有原文引用的采购清单，再通过人工确认和确定性规则，在采购前发现预算、规格及材料缺口。

## 目标用户与问题

学生社团组织者往往需要同时核对活动策划、报价、预算和票据条件。手动转录容易遗漏或误读规格，随意填写“已确认”也容易掩盖证据缺失。

## 实际能力

模型负责从粘贴文本中抽取物资、数量、单价和规格。每个字段保留可定位的原文片段；无法定位的引用由服务端拒绝。系统不让模型确认审批或执行付款。用户核对清单后，规则计算预算、比较明确长度单位，并提示审批和证据状态。导出报告保留原文、人工修改、模型及规则版本。

资料分为用户声明、有材料未核验、人工核验记录三种状态。后一种只是使用者记录，平台不保证附件、审批或供应商真实有效。可选一份学校官网制度的部分条款参考，适用范围须由使用者明确确认。

## 演示案例

合成活动预算¥500，报价总额¥536；存在展架规格冲突、审批未完成和未核验证据。横幅需求3m×0.8m与报价300cm×80cm按等价长度处理。人工更正价格和展架规格后，总额¥496；仍保留审批和材料待办，不输出虚假的“全部合规”。
