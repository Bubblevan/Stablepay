# PAYATHON：沙箱付款与报告交付演示顺序

更新：2026-10-28。演示地址：https://bubblevan.de5.net/payathon 。

## 演示前准备

- 电脑浏览器打开上面的公网地址，保留“支付宝沙箱”标记。
- 准备支付宝沙箱买家账号、登录密码和支付密码；密码输入过程暂停录制或剪去，不录密钥及开发者后台。
- 使用网页默认的合成采购资料：活动采购预算¥500，物资合计¥536。服务费上限¥1不是应付费用，也不是采购预算。
- 本脚本选择“活动预算核算”，应付服务费¥0.01。另一项“采购清单联合预审”为¥0.03，报告范围不同，不混用两项服务的演示结论。
- 已付款的订单可直接展示报告，不用重复付款。若要录制完整下单过程，可在新浏览器配置文件中创建新演示订单，同时保留原浏览器的已付款记录。无痕窗口只用于新订单，不能恢复原订单。

## 约三分钟录屏顺序

| 顺序 / 参考时间 | 页面操作 | 可以照读的说明 |
| --- | --- | --- |
| 1 / 0:00–0:20 | 展示网页的沙箱标记、默认需求、¥500采购预算与清单 | “这是采购任务助手。本次使用合成资料和支付宝沙箱，演示购买预算核算报告。” |
| 2 / 0:20–0:40 | 点击“整理需求并发现服务 →” | “系统按任务发现可用的自营核验服务。当前公网版本使用规则规划。” |
| 3 / 0:40–1:00 | 找到“活动预算核算”，点击“获取此服务报价” | “本次服务费是1分钱，与500元活动采购预算分别管理。” |
| 4 / 1:00–1:20 | 展示商户“StablePay 自营工具”和¥0.01；勾选“我确认服务、商户和费用，按此报价创建订单”，点击“确认并创建订单” | “付款前由用户确认服务、商户和固定报价。” |
| 5 / 1:20–1:40 | 点击“准备支付宝沙箱收银台”，再点“前往沙箱付款 ↗” | “系统跳转到支付宝官方沙箱收银台。” |

| 8 / 2:20–2:45 | 展示报告的预算¥500、合计¥536、超预算¥36 | “这份报告只核算预算。本次清单超过预算36元，不代表审批、规格或票据已经核验。” |
| 9 / 2:45–3:00 | 点击“下载报告与交易回执 ↓”，展示下载完成 | “报告和交易回执可以导出。本次完成的是沙箱付款与报告交付闭环。” |

报价五分钟有效，录制前不要提前生成报价后长时间停留。若报价已过期，重新获取报价即可。若收银台只提供扫码，使用官方沙箱支持的付款方式；不要用日常支付宝账号代替沙箱买家。

下载文件为 `stablepay-receipt.json`，包含报告、订单事件、报价及报告内容摘要。它是业务回执，不是发票。分享前遮盖交易标识、会话关联信息和自行填写的资料；公开演示优先展示网页中的报告部分。
