# 运维手册

## 1. 双网关职责

- 外层阿里云 API Gateway：公网入口、域名、基础路由、WAF/运维接入
- 内层 api-gateway：鉴权、限流、统一响应、协议兼容、下游转发

## 2. 部署建议

- 推荐容器部署，使用仓库 `Dockerfile`
- 通过环境变量或配置中心管理敏感配置
- 外层网关仅转发到内层服务，不重复业务中间件

## 3. 健康检查

- Liveness: `GET /healthz`
- Readiness: `GET /readyz`

## 4. 观测与排障

- 检索 `request_id` 做全链路定位
- 关注响应中 `code` 字段与 HTTP 状态码
- 常见异常：
  - `10004`：签名或时间窗错误
  - `30004`：限流触发
  - `30002`：下游不可用

## 5. 限流策略

- 默认：IP `100/min`，DID `50/min`
- 支付接口：`10/min`
- 查询接口：`30/min`
- API Key 验证类接口：`100/min`

## 6. 优雅停机

- 由 Hertz + 容器编排优雅退出
- 发布时建议 RollingUpdate，避免流量中断
