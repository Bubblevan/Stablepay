2. 验证时间戳窗口（`allowed_timestamp_skew_sec`）
3. 构建 Canonical 请求（Body SHA256 + 时间戳 + Nonce）
4. 调用 DID Service 验证签名
5. Nonce 去重检查（Redis/Memory）

**结论**：API Gateway 不是"待联调"，而是网关层功能完备，只差接入真实下游客户端。
